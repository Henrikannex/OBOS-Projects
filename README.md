# Workflow automation

Mapped the manual reporting routines in Norway's largest housing cooperative and automated
the 3 workflows with the clearest return. The jobs extract, format and distribute data on a
fixed schedule, saving NOK 220,000 annually in working hours.

The work started as process mapping rather than code. Each recurring report was traced to
its source system and the time it took, and the three with the highest annual cost were
automated first. Every job extracts from source, formats to the reporting standard,
distributes on schedule, and fails visibly rather than delivering an incomplete report.

The savings figure is the organisation's own estimate. All three jobs are in daily use.

## No source in this repository

The work was done during employment and the code is confidential. It runs against the
organisation's internal systems, credentials and data schemas, and belongs to them. This
repository records what was built; the approach can be discussed, the code cannot be
published.
